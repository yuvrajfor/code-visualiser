# Backend workspace

This folder contains the Express/tRPC application, authenticated request handling, database helpers, AI story interpreter, parser analysis, capacity safeguards, and tests. Run the full application from the repository root with `pnpm dev`, and validate backend and shared contracts with `pnpm test` and `pnpm check`.

The code-structure analyzer parses JavaScript and TypeScript as source text only. Python, C, and Java use a conservative structural fallback until dedicated language parsers are added.
