# HackerA Reference Findings

## Observed product language

The reference uses an editorial developer-product style rather than a conventional dark SaaS dashboard. Its main characteristics are a warm off-white page ground, heavy black outlines, blocky all-caps labels, a compact top navigation bar, and a small but energetic accent palette. Purple is reserved for the primary action and headline emphasis, lime communicates active or live state, while warm yellow, orange, and pink punctuate the illustrated frame.

The interface establishes hierarchy through large asymmetric headline typography, a lime note-like description block, and an adjacent hand-built illustration. Search and filtering are treated as a single outlined control deck below the hero. Cards and controls use crisp rectangular borders, modest corner radii, and deliberate hard shadows rather than translucent gradients.

## Code Story Studio adaptation

Code Story Studio should retain its existing interactive 3D learning canvas but adopt a compatible original system: a warmer paper-like shell for the standard theme; ink borders and compact navigation; purple as the clear action color; lime for active progress; and small geometric learning signals in place of the reference site’s hackathon motifs. The existing High Contrast theme must remain a separate accessibility override and must not inherit the paper palette.

The redesign should treat the code-entry panel as the central "learning deck," then pair it with a concise story-status rail and a framed cinematic scene. It should not copy the reference’s wording, illustrations, or exact component shapes.
