# Explanation Motion Reference Findings

**Source:** User-provided video, `/home/ubuntu/upload/20260818_210311.mp4`, reviewed on 2026-08-18.

The reference demonstrates a learner-controlled, split-pane execution flow. Source code stays visible as the stable anchor, while the adjacent visual area updates in discrete steps. The most transferable pattern is not decorative animation; it is a clear, manual pace where each step reveals one meaningful state change.

The explanation treatment should therefore use a compact, internally scrollable narrative rail. It should keep the active explanation anchored near the top, retain earlier explanations as a short readable history, and let the learner control navigation with direct steps rather than automatic global-page motion. Important execution context belongs near the controls as quiet metadata, for example, the current step out of the total.

The reference also keeps complex history inside bounded panels rather than extending the entire page. Code Story Studio will adapt this principle through an explanation panel with internal scrolling and reduced-motion-safe transitions, while retaining its original real-world visual scene instead of adopting Python Tutor’s memory-diagram design or branding.
